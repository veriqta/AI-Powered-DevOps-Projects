# Portfolio Guidance

A portfolio should demonstrate engineering judgment, not only successful commands.

For each project, explain:

- The operational problem
- The users and constraints
- The architecture and important trade-offs
- Your implementation decisions
- How deterministic logic and AI responsibilities differ
- Security and trust boundaries
- Tests and failure exercises
- Observability and acceptance evidence
- Cost and performance findings
- Limitations and next improvements

Use sanitized screenshots, short demonstrations, diagrams, test reports, and selected output. Never publish secrets or private infrastructure details. Be prepared to reproduce the project and explain any code included in your repository.

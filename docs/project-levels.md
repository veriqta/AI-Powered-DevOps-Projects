# Project Levels

## Foundation

Foundation projects introduce a focused engineering problem while still requiring a functioning system, tests, security controls, verification, troubleshooting, and cleanup.

## Intermediate

Intermediate projects connect several components and require deployment, CI/CD, observability, failure handling, and documented design decisions.

## Advanced

Advanced projects address distributed systems, scale, governance, multi-environment operations, complex security boundaries, or approval-controlled automation.

## Capstone

Capstones combine several disciplines into an end-to-end platform. They require architecture decisions, operational evidence, failure testing, cost analysis, security review, and a defensible production-readiness conclusion.

A level describes scope and complexity. It does not excuse incomplete safety, testing, or cleanup.

# Automation Scripts

| Script | Purpose |
|---|---|
| `setup.sh` | Create a virtual environment and install the project. |
| `verify-environment.sh` | Check required local tools and versions. |
| `validate-samples.sh` | Validate supplied JSON fixtures. |
| `run-sample.sh` | Generate reports for all local fixtures. |
| `run-live-github.sh` | Triage an explicitly selected GitHub Actions run. |
| `generate-report.sh` | Generate one report from a selected fixture. |
| `cleanup.sh` | Remove generated project output, preserving source and fixtures. |

Inspect scripts before running them. Execute them from the project root.

# Failure Exercises

These controlled exercises test operational judgment, not only happy-path functionality.

| Exercise | Primary skill |
|---|---|
| [Permission failure](scenario-01-permission-failure.md) | Least-privilege diagnosis |
| [Unknown classification](scenario-02-unknown-classification.md) | Evidence-based uncertainty |
| [Prompt injection](scenario-03-prompt-injection.md) | Treating logs as untrusted data |
| [Malformed model response](scenario-04-malformed-model-response.md) | Safe AI degradation |
| [Redaction regression](scenario-05-redaction-regression.md) | Incident containment and tests |

Use only synthetic data and disposable test credentials. Record the hypothesis, evidence, action, result, and control improvement for every exercise.

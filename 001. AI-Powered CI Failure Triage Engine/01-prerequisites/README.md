# Prerequisites

## Required Knowledge

You should understand:

- Basic Linux or terminal navigation
- Files, directories and environment variables
- Basic Python functions, modules and exceptions
- JSON
- Basic Git branches and commits
- The purpose of CI pipelines
- Basic GitHub Actions concepts such as workflows, jobs and steps

Advanced AI or machine-learning knowledge is not required.

## Required System

Use one of:

- Linux
- macOS
- Windows with WSL 2
- A Linux virtual machine

Required tools:

- Python 3.11 or newer
- Git
- A code editor
- A terminal
- Internet access only for installation, live GitHub mode or optional AI mode

## Optional Access

- A GitHub account for live API mode
- A fine-grained GitHub token with **Actions: read** for private repositories
- An approved OpenAI-compatible endpoint for optional AI explanations

Local fixture mode needs no GitHub token and no AI key.

## Resource Requirements

- 2 CPU cores
- 2 GB available memory
- 500 MB available disk space

The project has no required cloud cost. Model charges apply only if optional AI mode is enabled.

[Home](../../README.md) > Project 090

**Level:** Capstone

## Project overview

Manage risk discovery, experiment design, fault injection, recovery evidence, readiness scoring, and preventive work.

## What you will build

This project will provide a complete follow-along implementation, not only a design exercise. The finished project will include working code, reproducible setup, automated tests, operational evidence, controlled failure scenarios, recovery procedures, and a production-readiness review.

## Expected project resources

The full release will include:

- Project-specific prerequisites
- System and repository setup
- Architecture, data flow, and security boundaries
- Numbered implementation labs
- A complete walkthrough with expected results
- Starter files and a tested reference implementation
- Infrastructure as code where infrastructure is required
- CI/CD integration
- Tests and acceptance criteria
- Logs, metrics, traces, dashboards, or alerts where applicable
- AI safety controls and output validation
- Failure scenarios, investigation, recovery, and verification
- Cost, performance, and capacity considerations
- Cleanup instructions
- Troubleshooting guidance
- Interview and portfolio preparation

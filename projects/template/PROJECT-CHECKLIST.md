# Project Readiness Checklist

## Problem and Scope

- [ ] Real operational user and decision are named.
- [ ] AI use is justified.
- [ ] Required path fits the declared level.
- [ ] Similar catalogue projects are distinguished.

## Implementation

- [ ] Setup works from a fresh clone.
- [ ] Normal workflow produces documented output.
- [ ] Deterministic logic and AI responsibilities are separate.
- [ ] Model-disabled behavior is safe.
- [ ] Cleanup is scoped and repeatable.

## Quality

- [ ] Unit and integration tests pass.
- [ ] Failure and misuse paths are tested.
- [ ] CI and security checks pass.
- [ ] Architecture matches implementation.
- [ ] No secrets or real sensitive data are present.
- [ ] Limitations and costs are documented.

## Review

- [ ] Technical review complete.
- [ ] Security review complete.
- [ ] Learner usability review complete.
- [ ] Project status updated in the catalogue.

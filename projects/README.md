# Projects

This directory contains the 100 projects listed in the main [Project Catalogue](../README.md#project-catalogue).

Each numbered directory has a stable project identifier and public landing page. Project status is stated inside the project README.

## Status meaning

| Status | Meaning |
| --- | --- |
| Planned | The project has a defined outcome but is not ready to follow. |
| In development | Guides, implementation, and validation are being produced. |
| Review | The complete project is undergoing technical and learning-path review. |
| Ready | The project can be completed from beginning to end. |
| Maintenance | The ready project receives dependency, security, and documentation updates. |

Do not interpret the existence of a numbered folder as evidence that its full implementation is ready.

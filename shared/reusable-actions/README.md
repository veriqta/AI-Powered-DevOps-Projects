# Reusable Actions

This folder is reserved for reviewed CI building blocks used by multiple projects.

Before adding one:

- demonstrate use in at least two approved projects;
- pin third-party dependencies;
- declare permissions;
- avoid secret exposure;
- document inputs, outputs and failure behavior;
- test pull-request and default-branch behavior;
- assign an owner and update policy.

Project-specific workflows remain in that project's `.github/workflows` folder.
